# Android Air Drop

AirDrop-style nearby sharing for **Android ↔ Android** and **Android ↔ Windows**:
one-tap discovery, a "bring phones together" gesture, fluid animations, and transfers
that run over the fastest radio both devices share.

- Architecture and build plan: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

> Working name only. "AirDrop" is an Apple trademark, so ship under your own name and
> visual identity (see *Legal* in the architecture doc).
